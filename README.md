# Campus Lost & Found Portal (CLFP)

## Project Purpose
A web application for the students, faculty, and staff of FAST-NUCES Chiniot-Faisalabad Campus to report lost items, report found items, search listings, and submit verified claim requests to recover their belongings.

## Group Members
- Ali Raza (22F-3399) — Project Manager & Backend Developer
- Abdullah Farooq (22F-3421) — UI/UX Designer & Frontend Developer & QA

## Technologies Used
- HTML5, CSS3, JavaScript (vanilla)
- Browser localStorage as a lightweight mock data layer for this stage of the project

## How to Run
Clone the repository and open `index.html` in a browser. No build step or server is required.
